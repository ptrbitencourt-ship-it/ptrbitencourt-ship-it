## 🚀 Projetos em destaque

### Porsche Sales Intelligence

**Dashboard executivo para análise e visualização de dados de vendas.**

Projeto desenvolvido para transformar registros de vendas em indicadores e visualizações interativas.

**Tecnologias:** HTML5 • CSS3 • JavaScript • Chart.js

**Principais recursos:**

- KPIs de vendas
- Receita total
- Ticket médio
- Ranking de modelos
- Análise por cidade
- Métodos de pagamento
- Evolução das vendas por ano
- Filtros interativos
- Gráficos dinâmicos
- Business Insights
- Interface responsiva
